# こーるみー!!!

WireGuard内でIP電話をするためのシンプルなProxyです。
自宅VPNでの利用のために開発しているため、それ以外の環境では調整が必要な場合があります。

## 発信フロー (phone1 -> phone2)

```
[phone1]        [callme1]          [callme2]        [phone2]
   |                |                   |                |
   |--INVITE------->|                   |                |
   |  SDP: phone1   | SDP書換           |                |
   |                |--INVITE---------->|                |
   |                |  SDP: callme1     | SDP書換        |
   |                |                   |--INVITE------->|
   |                |                   |  SDP: callme2  |
   |                |                   |                |
   |                |                   |<--200 OK-------|
   |                |                   |  SDP: phone2   |
   |                | SDP書換           |                |
   |                |<--200 OK----------|                |
   |                |  SDP: callme2     |                |
   | SDP書換        |                   |                |
   |<--200 OK-------|                   |                |
   |  SDP: callme1  |                   |                |
   |                |                   |                |
   |--ACK---------->|--ACK------------->|--ACK---------->|
   |                |                   |                |
   |<=====RTP======>|<=====RTP=========>|<=====RTP======>|
   |                |                   |                |
   |--BYE---------->|--BYE------------->|--BYE---------->|
   |                |                   |<--200 OK-------|
   |                |<--200 OK----------|                |
   |<--200 OK-------|                   |                |
```
